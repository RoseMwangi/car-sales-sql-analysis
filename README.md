# Car Sales SQL Analysis & Dashboard 📊

This project showcases how I used SQL to clean, analyze, and visualize car sales data using Google BigQuery and Looker Studio.

## 📁 Dataset
- Format: CSV
- Source: kaggle datasets
- Size: ~558837 rows
- Fields: make, model, sellingprice, saledate, odometer, etc.

## 🛠 SQL Concepts Covered
- Data Cleaning: standardizing formats, fixing dates, handling nulls
- Aggregation: monthly sales, top brands, state-level totals
- CTEs and CASE statements
- Outlier detection and value bucketing
- Regular expressions
- Joins and filtering

## 📌 Key Insights
- Most sold car brands and colors
- Average price by mileage category
- Monthly revenue trends
- Highest grossing states
- Most expensive luxury brands
